# Генератор страниц программных модулей

Собирает страницы `content/Программные модули/**/*_sw.md` из двух источников:

- **манифест прошивки** — топики, опции с диапазонами и значениями по умолчанию,
  события и команды. Берётся из сгенерированных заголовков
  `moduleBox/build/esp-idf/*/generated_files/gen_*.h`;
- **авторская проза** — описание, принцип работы, примеры, схемы. Лежит
  в `pages_data*.py`.

Смысл в том, чтобы механическая часть страниц не расходилась с прошивкой:
после изменения модуля достаточно пересобрать прошивку и перегенерировать страницы.

## Использование

```sh
# 1. собрать прошивку (чтобы gen_*.h были актуальны), затем:
python tools/pages_gen/extract.py          # gen_*.h -> manifest_all.json
python tools/pages_gen/gen_pages.py        # manifest_all.json + проза -> content/
```

`extract.py` кладёт `manifest_all.json` рядом со скриптами — пути к сборке
и к выходному файлу заданы константами в начале обоих скриптов, поправьте их
под свою машину.

## Файлы

| Файл | Что внутри |
|---|---|
| `extract.py` | разбор `gen_*.h` в единый JSON |
| `gen_pages.py` | сборка markdown: форматирование опций, таблиц событий и команд |
| `pages_data.py` | проза: кнопки и подсветка |
| `pages_data_2.py` | проза: датчики, входы-выходы, силовые модули |
| `pages_data_3.py` | проза: виртуальные, звук, служебные |

## Оговорки

- Модули без манифеста (`rfid`, `uartLogger`, `ds18b20`, `steadywinGIM`, `CRSF`,
  `VESC`, `PPM`, `furbyEye`, `st7789`, `HID`) генератором не покрыты — их страницы
  пишутся руками.
- Генератор **перезаписывает** страницы целиком. Правку прозы вносите в
  `pages_data*.py`, иначе она потеряется при следующем запуске.
- Формат страниц задан [DOCUMENTATION_SKILL.md](../../DOCUMENTATION_SKILL.md).
