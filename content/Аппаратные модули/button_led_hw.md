## Описание
Модуль для подключения кнопки с одноцветной подсветкой: один вход для
контакта кнопки и один силовой выход для светодиода. Обеспечивает надёжное
взаимодействие механических переключателей с цифровой системой.

- Вход `bt` — сухой контакт: кнопка замыкает `bt` на `gnd`, внешнее питание
  для неё не нужно. Вход защищён от статики.
- Выход `led+` — P-MOSFET верхнего плеча: во включённом состоянии выдаёт
  напряжение шины Vbus, в выключенном — 0 В. Подсветка включается между
  `led+` и `gnd`, поддерживается ШИМ. Токоограничивающего резистора на
  модуле нет — светодиод в кнопке должен быть рассчитан на Vbus.

Назначение контактов разъёма (сверху вниз):

| Контакт | Назначение |
|---|---|
| `led+` | плюс подсветки (Vbus при включении) |
| `gnd` | минус подсветки |
| `gnd` | второй контакт кнопки |
| `bt` | контакт кнопки |

## Питание
Выход `led+` питается от шины [[Платформа moduleBox/Hardware#Шина питания Vbus|Vbus]] через самовосстанавливающийся предохранитель F1: в неактивном состоянии 0 В, в активном — напряжение Vbus.

## Схема подключения
![[Аппаратные модули/_assets/button_led.svg]]

Кнопка 300-001 подключается четырьмя проводами: светодиод — на `led+` и
`gnd`, контакт — на `bt` и второй `gnd`.

## Индикация
Светодиод D1 отображает состояние кнопки (горит при замкнутом контакте).
Светодиод D2 отображает состояние подсветки.
