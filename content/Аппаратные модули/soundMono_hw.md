## Описание
Модуль предназначен для воспроизведения аудио сигнала. Построен на микросхеме *MAX98357AETE+T*, со встроенный ЦАП и усилителем класса D. 

Максимальная мощность: 3.2 Вт для динамика сопротивлением 4ом.

## Совместимость
[[Программные модули/Звуковые модули/mp3Player_sw|audioPlayer]]


## Питание
По умолчанию модуль питается от внутреннего малошумного преобразователя на 3.3В. С помощью перемычки JP2 питание микросхемы можно подключить к шине 5В для увеличения мощности(микросхему U1 необходимо удалить).


## Коэффициент усиления
С помощью перемычки и резистора R4 можно изменить коэффициент усиления:

| коэффициент | резистор R4 | перемычка |
| ----------- | ----------- | --------- |
| 3dB         | 100 k       | Vin       |
| 6dB         | 0 om        | Vin       |
| 9dB         | 0 om        | NC        |
| 12dB        | 0 om        | Gnd       |
| 15dB        | 100 k       | Gnd       |
