## Описание
Модуль трёх цифровых входов для сухих контактов: кнопки, герконы, концевые
выключатели, контакты реле. Обеспечивает надёжное взаимодействие
механических переключателей с цифровой системой.

- Каждый вход — сухой контакт: контакт замыкает `ch_N` на `gnd`, внешнее
  питание не нужно. Дребезг подавляется программно.
- Входы опрашиваются через оптроны и защищены от статики.
- Датчики с собственным питанием (NPN/PNP) к этому модулю не подключаются —
  для них есть [[Аппаратные модули/in_2ch_hw|in_2ch]].

Назначение контактов разъёма (сверху вниз):

| Контакт | Назначение |
|---|---|
| `ch_2` | вход канала 2 |
| `ch_1` | вход канала 1 |
| `ch_0` | вход канала 0 |
| `gnd` | общий |

## Питание
На разъёме нет вывода питания — модуль рассчитан только на сухие контакты.
Цепь опроса питается от внутреннего источника контроллера, от шины Vbus
модуль не зависит.

## Схема подключения
![[Аппаратные модули/_assets/in_3ch.svg]]

Каждый контакт подключается двумя проводами — между своим `ch_N` и `gnd`.
Провод `gnd` общий для всех трёх каналов.

## Индикация
Светодиоды D1, D2, D3 отображают состояние каналов — горят при замкнутом
контакте.
