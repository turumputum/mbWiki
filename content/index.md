# Модульбокс википедия

moduleBox — программно-аппаратный комплекс с модульной архитектурой: из доступных
модулей собираются самые разные устройства.

Настройки, режимы работы и внутренние связи задаются в конфигурационном файле —
устройство можно применять с минимальными познаниями в программировании. Формат
конфигурации через файл позволяет дистанционно отлаживать и резервировать настройки.
