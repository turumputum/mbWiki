Программный модуль реализует аналоговый вход. 
~~Диапазон измерений: 0-5в.~~
~~Разрядность 12бит(0-4095).~~
## Совместимость:
- ~~[[Аппаратные модули/inOut_hw|inOut]]~~

## Принцип работы
Рапортует об изменении состояния аналогово сигнала на входе. Значение может быть передано без изменений, в виде целочисленного числа и числа с плавающей точкой. Опционально можно настроить рабочий диапазон с помощью верхней и нижней границы измерений. Предусмотрен фильтр "Скользящая средняя" и возможность настроить зону нечувствительности.


## Топики
Стандартный топик события:
- *"deviceName/analog_{slot_num}"* - {slot_num} номер слота
	- пример: "deviceName/in_0"


## Опции
- **float_output** - *флаг*, выходное значение будет формироваться в виде переменной с плавающей точкой, от нуля до единицы.
- **max_val** - *число*(int), верхняя граница измерений.
- **min_val** - *число*(int), нижняя граница измерений.
- **inverse** - *флаг*, инверсия значений.
- **filter_k** - *число(float)*, коэффициент фильтрации, от нуля до единицы.
- **dead_band** - *число*(int), размер зоны не чувствительности, по умолчанию 10.
- **custom_topic** - не стандартный топик событий.



Пример настройки выходного сигнала:
```ini
options = out_delay_ms:1000, out_impulse_ms:500
```
Выходной сигнал будет сформирован виде импульса продолжительностью 500мс с задержкой в 1сек.

Пример использование cross_link:
```ini
cross_link = in_0:1->out_0:1; turn on out_0 when in_0 is up
```
