## Описание
Программный модуль для приёма и воспроизведения аудио потока по локальной сети через протокол RTP (multicast). Позволяет выбирать группу и канал вещания, управлять громкостью и состоянием воспроизведения.

| Протокол     | RTP multicast |
| ------------ | ------------- |
| Самплрэйт    | 48000 Hz      |
| Разрядность  | 16 бит        |
| Каналы       | 2 (стерео)    |

## Принцип работы
Модуль подключается к multicast-группе по адресу `239.0.{group}.{channel}` на заданном порту и воспроизводит входящий аудио поток. При запуске ожидает инициализации сетевого интерфейса. Рапортует текущее состояние, канал и громкость.
==Требуется подключение к локальной сети (LAN).==

## Топик
Стандартный топик событий и действий:
- *"deviceName/audioLAN_{slot_num}"* - {slot_num} номер слота
	- пример: "deviceName/audioLAN_0"

## Опции
Доступные опции:
- **defaultState** - *число(int)*, состояние модуля при включении (0 — выкл, 1 — вкл). По умолчанию 1.
- **volume** - *число(int)*, уровень громкости, от 0 до 100. По умолчанию 100.
- **group** - *число(int)*, номер группы multicast-адреса (третий октет: 239.0.**X**.0), от 0 до 255. По умолчанию 7.
- **channel** - *число(int)*, номер канала multicast-адреса (четвёртый октет: 239.0.7.**X**), от 0 до 255. По умолчанию 0.
- **port** - *число(int)*, номер UDP-порта для приёма потока, от 0 до 65535. По умолчанию 7777.
- **topic** - *строка*, нестандартный топик событий и действий.

## Команды
- **/setState** — включение/выключение воспроизведения, возможные значения 0-1.
	- Пример: "*moduleBox/audioLAN_0/setState:1*"
- **/setChannel** — переключение канала (четвёртый октет multicast-адреса), значение от 0 до 255.
	- Пример: "*moduleBox/audioLAN_0/setChannel:5*"
- **/setVolume** — установка уровня громкости, значение от 0 до 100.
	- Пример: "*moduleBox/audioLAN_0/setVolume:80*"

## События
- **/state** — рапортует текущее состояние модуля (0 — выкл, 1 — вкл). Пример:
	"*moduleBox/audioLAN_0/state:1*"
- **/volume** — рапортует текущий уровень громкости. Пример:
	"*moduleBox/audioLAN_0/volume:80*"
- **/channel** — рапортует текущий номер канала. Пример:
	"*moduleBox/audioLAN_0/channel:5*"

## Индикация
- Светодиод **выключен** — модуль в состоянии DISABLE.
- Светодиод **горит постоянно** — модуль включён, поток принимается.
- Светодиод **мигает** — модуль включён, но поток не обнаружен.

## Примеры

```ini
[SLOT_0]
mode = audioLAN
;громкость 80%, группа 7, канал 3, порт по умолчанию
options = volume:80, group:7, channel:3
crosslink = button_1:1->audioLAN_0/setState:1, button_1:0->audioLAN_0/setState:0
;включить/выключить воспроизведение по нажатию кнопки
```

Переключение каналов через кнопки:
```ini
[SLOT_0]
mode = audioLAN
options = volume:100, channel:0

[SLOT_1]
mode = button_led
options = empty
;переключение между каналами 0 и 1
crosslink = button_1:1->audioLAN_0/setChannel:1, button_1:0->audioLAN_0/setChannel:0
```
