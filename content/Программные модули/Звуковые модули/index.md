Четыре программных модуля воспроизведения звука. Два играют файлы с носителя,
два принимают поток по сети. Все работают **только в нулевом слоте** и с любым
из трёх звуковых аппаратных модулей.

| Модуль | Источник | База топика | Особенности |
|---|---|---|---|
| [mp3Player](<Программные модули/Звуковые модули/mp3Player_sw.md>) | файлы .mp3 с [карты памяти](<Аппаратные модули/SD_card_hw.md>) | `player_<slot>` | скорость, тональность, эквалайзер |
| [wavPlayer](<Программные модули/Звуковые модули/wavPlayer_sw.md>) | файлы .wav с карты памяти | `player_<slot>` | те же опции, без декодирования — быстрее старт |
| [audioLAN](<Программные модули/Звуковые модули/audioLAN_sw.md>) | RTP-поток по сети, без сжатия | `audioStream_<slot>` | задержка ~70 мс, нужна быстрая сеть |
| [opusLAN](<Программные модули/Звуковые модули/opusLAN_sw.md>) | RTP-поток по сети, кодек Opus | `audioStream_<slot>` | задержка ~100 мс, синхронное воспроизведение на нескольких приёмниках (**latencyMs**) |

Аппаратная часть — один из модулей: [soundMono](<Аппаратные модули/soundMono_hw.md>)
(динамик), [soundStereo](<Аппаратные модули/soundStereo_hw.md>) (активная
акустика, наушники), [soundAmp](<Аппаратные модули/soundAmp_hw.md>) (пассивные
колонки).

## Проигрыватели
`mp3Player` и `wavPlayer` управляются одинаково: `action/play` с номером трека,
приращением `+N`/`-N`, `random` или `#` (текущий), `action/stop`,
`action/shift`, `action/setVolume`; по окончании трека — `event/endOfTrack`.
Треки нумеруются с нуля в алфавитном порядке имён файлов.

## Сетевые приёмники
`audioLAN` и `opusLAN` принимают unicast-поток на порт **port** либо
multicast-группу **multicastAddress**; адрес меняется на лету командой
`action/setMulticastAddress`. Рапортуют `event/volume` и `event/address`.
Источник потока на ПК — приложение [[Программные модули/Звуковые модули/AntiDante|AntiDante]].

## Пример
```ini
[SLOT_0]
mode = mp3Player
options = volume:80
[SLOT_1]
mode = button_led
;нажатие - следующий трек
crosslink = button_1/event/press:1->player_0/action/play:+1
```

Подробнее — [[Платформа moduleBox/CrossLink|внутренние связи (crossLink)]].
