Семейство базовых дискретных модулей — компонент `in_out` прошивки. Входы
рапортуют состояние контакта или датчика, выходы исполняют команды
«включить / выключить / переключить / импульс».

| Модуль | Роль | База топика | Аппаратный модуль |
|---|---|---|---|
| [in_2ch](<Программные модули/Входы и выходы/in_2ch_sw.md>) | два входа, логика `independent` / `or` / `and` | `in_<slot>` | [in_2ch](<Аппаратные модули/in_2ch_hw.md>) |
| [in_3ch](<Программные модули/Входы и выходы/in_3ch_sw.md>) | три входа, та же логика | `in_<slot>` | [in_3ch](<Аппаратные модули/in_3ch_hw.md>) |
| [in_out](<Программные модули/Входы и выходы/in_out_sw.md>) | вход + выход в одном слоте | `in_<slot>` / `out_<slot>` | [in_out](<Аппаратные модули/in_out_hw.md>) |
| [out_2ch](<Программные модули/Входы и выходы/out_2ch_sw.md>) | два выхода | `out_<slot>` | [out_2ch](<Аппаратные модули/out_2ch_hw.md>) |
| [out_3ch](<Программные модули/Входы и выходы/out_3ch_sw.md>) | три выхода | `out_<slot>` | [3n_mosfet](<Аппаратные модули/3n_mosfet_hw.md>), [out_2ch](<Аппаратные модули/out_2ch_hw.md>) |
| [relay](<Программные модули/Входы и выходы/relay_sw.md>) | один выход на реле | `relay_<slot>` | [relay](<Аппаратные модули/relay_hw.md>) |
| [tachometer](<Программные модули/Входы и выходы/tachometer_sw.md>) | частота импульсов на входе | `tachometer_<slot>` | [in_2ch](<Аппаратные модули/in_2ch_hw.md>), [in_out](<Аппаратные модули/in_out_hw.md>) |

## Входы
Каждый канал рапортует `event/ch_N` при изменении, инверсия — **inverse_N**,
антидребезг — **inDebounceGap**. Опция **logic** объединяет каналы: в режиме
`or` / `and` вместо отдельных каналов рапортуется общий `event/val`;
**refreshPeriod** задаёт периодический рапорт.

## Выходы
Каналы принимают `action/ch_N` (`0` / `1`), `action/ch_N/toggle` и
`action/ch_N/impulse` с длительностью в миллисекундах; стартовое состояние —
**defState_N**, инверсия — **inverse_N**. У relay и in_out канал один, поэтому
команды называются `setVal` / `toggle` / `impulse` без номера канала.
Все выходные модули поддерживают `enable` и **disableOnStart**.

## Пример
```ini
[SLOT_1]
mode = in_2ch
;кнопка на входе 0 включает реле, на входе 1 - выключает
crosslink = in_1/event/ch_0:1->relay_2/action/setVal:1, in_1/event/ch_1:1->relay_2/action/setVal:0

[SLOT_2]
mode = relay
options = defState:0
```
