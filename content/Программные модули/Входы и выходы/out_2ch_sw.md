```ini
[SLOT_n]
mode = out_2ch
```
Программный модуль двух цифровых выходов.

## Совместимость
- [[Аппаратные модули/out_2ch_hw|Модуль два цифровых выхода]]
- [[Аппаратные модули/3n_mosfet_hw|Модуль три силовых MOSFET-ключа]]

## Принцип работы
Модуль исполняет входящие команды и состоянием входа не занимается —
событий, кроме `enable`, у него нет.

Каждый канал инвертируется опцией `inverse_N` и получает стартовое состояние
опцией `defState_N`. Помимо прямой установки значения, канал умеет переключаться
командой `toggle` и формировать импульс заданной длительности командой `impulse`.

## Топики
База топика действия:
- `<deviceName>/out_<slot>` — например `moduleBox/out_0`

Полный топик — база плюс направление и имя: `moduleBox/out_0/action/ch_0`.

## Опции
Доступные опции:
- **disableOnStart** — *флаг*, стартовать в выключенном состоянии и ждать `action/enable` со значением `1`. По умолчанию модуль активен сразу.
- **inverse_0** — *число(int)*, инверсия выхода канала 0. Диапазон 0–1. По умолчанию 0.
- **inverse_1** — *число(int)*, инверсия выхода канала 1. Диапазон 0–1. По умолчанию 0.
- **defState_0** — *число(int)*, состояние канала 0 при старте. Диапазон 0–1. По умолчанию 0.
- **defState_1** — *число(int)*, состояние канала 1 при старте. Диапазон 0–1. По умолчанию 0.

## События
| Топик | Payload | Описание |
|---|---|---|
| `out_<slot>/event/enable` | `0` / `1` | Активен 1 или спит 0 |

## Команды
| Топик | Payload | Описание |
|---|---|---|
| `out_<slot>/action/ch_0` | `0` / `1` | Установить состояние канала 0 |
| `out_<slot>/action/ch_1` | `0` / `1` | Установить состояние канала 1 |
| `out_<slot>/action/ch_0/toggle` | — | Переключить состояние канала 0 |
| `out_<slot>/action/ch_1/toggle` | — | Переключить состояние канала 1 |
| `out_<slot>/action/ch_0/impulse` | целое | Импульс на канале 0, длительность в $мСек$ |
| `out_<slot>/action/ch_1/impulse` | целое | Импульс на канале 1, длительность в $мСек$ |
| `out_<slot>/action/enable` | `0` / `1` | Включить (`1`) или выключить (`0`) модуль |

Пример: топик `moduleBox/out_0/action/ch_1/impulse`, payload `500`.

## Примеры
```ini
[SLOT_0]
mode = out_2ch
options = defState_0:1, inverse_1
;кнопка переключает первый канал, второй даёт импульс
crosslink = button_1/event/press:1->out_0/action/ch_0/toggle:1, button_1/event/longPress:1->out_0/action/ch_1/impulse:1000
```
Канал 0 включён при старте, канал 1 работает с инверсией сигнала.

Подробнее — [[Платформа moduleBox/CrossLink|внутренние связи (crossLink)]].
