```ini
[SLOT_n]
mode = relay
```
Программный модуль управления реле: включение, выключение, переключение и импульс заданной длительности.

## Совместимость
- [[Аппаратные модули/relay_hw|Модуль реле]]

## Принцип работы
Модуль исполняет входящие команды, управляя одним реле. Выход инвертируется
опцией **inverse**, стартовое состояние задаётся опцией **defState**.

Команда `impulse` включает реле на заданное число миллисекунд и выключает
самостоятельно — удобно для управления замками, пускателями и импульсными реле.

## Топики
База топика действия:
- `<deviceName>/relay_<slot>` — например `moduleBox/relay_0`

Полный топик — база плюс направление и имя: `moduleBox/relay_0/action/setVal`.

## Опции
Доступные опции:
- **disableOnStart** — *флаг*, стартовать в выключенном состоянии и ждать `action/enable` со значением `1`. По умолчанию модуль активен сразу.
- **inverse** — *число(int)*, инверсия выхода. Диапазон 0–1. По умолчанию 0.
- **defState** — *число(int)*, состояние при старте. Диапазон 0–1. По умолчанию 0.

## События
| Топик | Payload | Описание |
|---|---|---|
| `relay_<slot>/event/enable` | `0` / `1` | Активен 1 или спит 0 |

## Команды
| Топик | Payload | Описание |
|---|---|---|
| `relay_<slot>/action/setVal` | `0`–`1` | Установить реле |
| `relay_<slot>/action/toggle` | — | Переключить реле |
| `relay_<slot>/action/impulse` | целое | Импульс реле - длительность в мс |
| `relay_<slot>/action/enable` | `0` / `1` | Включить (`1`) или выключить (`0`) модуль |

Пример: топик `moduleBox/relay_0/action/impulse`, payload `500`.

## Примеры
```ini
[SLOT_0]
mode = relay
options = defState:1, inverse
;нажатие кнопки переключает реле
crosslink = button_1/event/press:1->relay_0/action/toggle:1
```
Реле включается при старте устройства с инвертированным выходным сигналом.

```ini
[SLOT_1]
mode = relay
;срабатывание датчика открывает замок на две секунды
crosslink = whitelist_6/event/val:1->relay_1/action/impulse:2000
```
