Программный модуль для работы с дисковыми номеронабирателями.

## Принцип работы
Модуль считывает два входных сигнала, один сигнализирует о начале набора цифры, второй генерирует импульсы. Собирает набранные цифры в строку до заданного размера или по таймауту. Рапортует в виде строки по окончанию набора номера.

## Аппаратные модули:
- [[Аппаратные модули/in_2ch_hw|in_2ch]]

## Топик
Стандартный топик событий и действий:
- *"deviceName/dialer_{slot_num}"* - {slot_num} номер слота
	- пример: "moduleBox/dialer_0"

## Опции
Доступные опции:
- **enaInverse** - *флаг*, инверсия ena сигнала.
- **waitingTime** - *число(int)*, время ожидания набора следующей цифры. Единица измерения $мСек$. По умолчанию 3000 $мСек$.
- **numberMaxLenght** - *число(int)*, максимальное число цифр в номере. По умолчанию 7.
- **debounceGap** - *число(int)*, интервал времени не чувствительный к дребезгу. Время в течение которого изменение состояния входа не будут рапортоваться. Единица измерения $мСек$. По умолчанию 20 $мСек$.
- **topic** - *строка*, нестандартный топик событий и действий.
Пример
 ```ini
 ; таймаут 1 секунда, максимальная длин номера 5 знаков
options=waitingTime:1000, numberMaxLenght:5
```

## Cобытия
- Отчет по завершению набора номера.

Пример использование [[cross_link]]:
```ini
;при наборе номера "03", проиграть трек номер 1
cross_link = dialer_2:03->player_0/play:1
```
В случае большого количества связей можно использовать модуль [[content/Программные модули/Виртуальные модули/whitelist_sw|whitelist_sw]]
```ini
;передать значение набранного номер в слот whitelist, в котором будут выполнены действия привяззаные к определенныим комбинациям
cross_link = dialer_2:@->whitelist_3:@
```
Подробнее об использовании [[Платформа moduleBox/Software#Внутренние связи(cross_link)|crossLink]]
