```ini
[SLOT_n]
mode = HID
```
Виртуальный модуль имитации USB-клавиатуры: устройство представляется хосту как
клавиатура и отправляет нажатия клавиш по командам.

## Совместимость
Виртуальный модуль, аппаратной части не требует — используется разъём USB самого
контроллера. Занимает слот из диапазона 0–9.

## Принцип работы
Модуль эмулирует нажатие клавиш USB-клавиатуры. Команды `press` и `release`
нажимают и отпускают клавишу по коду, `kick` делает то и другое с паузой 50 $мСек$ —
короткое нажатие.

Коды клавиш — стандартные HID Usage ID, см. [[#Коды клавиш]].

## Топики
База топика действия:
- `<deviceName>/HID_<slot>` — например `moduleBox/HID_6`

Полный топик — база плюс направление и имя: `moduleBox/HID_6/action/kick`.

Событий модуль не рапортует.

## Опции
Модуль дополнительных опций не имеет.

## Команды
| Топик | Payload | Описание |
|---|---|---|
| `HID_<slot>/action/press` | целое, код клавиши | Нажать клавишу и удерживать |
| `HID_<slot>/action/release` | целое, код клавиши | Отпустить клавишу |
| `HID_<slot>/action/kick` | целое, код клавиши | Нажать и сразу отпустить клавишу |

Пример: топик `moduleBox/HID_6/action/kick`, payload `44` — короткое нажатие пробела.

> [!warning]
> Модуль не мигрирован на общий механизм команд и не попадает в `manifest.json`.
> Имена команд разбираются подстрокой, поэтому в конфигураторе он не появится,
> а список команд здесь выверен по исходникам прошивки.

## Примеры

```ini
[SLOT_2]
mode = button_led
;замыкание контактов имитирует нажатие "p", размыкание - "r"
crosslink = button_2/event/press:1->HID_3/action/kick:19, button_2/event/press:0->HID_3/action/kick:21

[SLOT_3]
mode = HID
```

Подробнее — [[Платформа moduleBox/CrossLink|внутренние связи (crossLink)]].
