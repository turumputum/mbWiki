```ini
[SLOT_n]
mode = timer
```
Виртуальный модуль таймера: рапортует по истечении заданного времени.

## Совместимость
Виртуальный модуль, аппаратной части не требует. Доступные слоты: 0-9.

## Принцип работы
Модуль ждёт команду `start`. Время отсчёта берётся из параметра команды, а если
он не задан или равен нулю — из опции **time**. По истечении времени модуль
рапортует событие `timerEnd`.

Отсчёт можно прервать в любой момент командой `stop`. Повторный `start` до
срабатывания перезапускает отсчёт с начала.

## Топики
База топика события:
- `<deviceName>/timer_<slot>` — например `moduleBox/timer_0`

База топика действия:
- `<deviceName>/timer_<slot>` — например `moduleBox/timer_0`

Полный топик — база плюс направление и имя: `moduleBox/timer_6/event/timerEnd`.

## Опции
Доступные опции:
- **disableOnStart** — *флаг*, стартовать в выключенном состоянии и ждать `action/enable` со значением `1`. По умолчанию модуль активен сразу.
- **time** — *число(int)*, время через которое сработает таймер, единицы измерения мс. По умолчанию 1000.

## События
| Топик | Payload | Описание |
|---|---|---|
| `timer_<slot>/event/timerEnd` | строка | Отчёт о срабатывании таймера |
| `timer_<slot>/event/enable` | `0` / `1` | Состояние модуля - активен 1 или спит 0 |

Пример: топик `moduleBox/timer_6/event/timerEnd`, payload `1`.

## Команды
| Топик | Payload | Описание |
|---|---|---|
| `timer_<slot>/action/start` | целое, $мСек$ (необязательно) | Запустить таймер Опционально - время таймера, если параметр не задан или равен 0 будет использован параметр заданный в опциях |
| `timer_<slot>/action/stop` | — | Остановить таймер |
| `timer_<slot>/action/enable` | `0` / `1` | Включить (`1`) или выключить (`0`) модуль |

## Примеры
```ini
[SLOT_6]
mode = timer
options = time:30000
;нажатие кнопки запускает таймер, по истечении - гаснет подсветка
crosslink = timer_6/event/timerEnd:1->led_0/action/enable:0
```

```ini
[SLOT_7]
mode = timer
;датчик присутствия перезапускает отсчёт, тишина в пять секунд останавливает трек
crosslink = timer_7/event/timerEnd:1->player_0/action/stop:1
```
Запуск таймера с нужным временем приходит извне или
[[Платформа moduleBox/CrossLink|внутренними связями]]: `distanceSens_0/event/threshold:1->timer_7/action/start:5000`.

Подробнее — [[Платформа moduleBox/CrossLink|внутренние связи (crossLink)]].
