Виртуальные модули не привязаны к железу: они обрабатывают события, хранят
состояние и запускают действия. Занимают слоты **0–9** (у контроллера шесть
физических слотов, слоты 6–9 — только для виртуальных модулей), связываются с
остальными через [[Платформа moduleBox/CrossLink|crossLink]].

| Модуль | Назначение |
|---|---|
| [startup](<Программные модули/Виртуальные модули/startup_sw.md>) | одно событие при загрузке — точка входа для стартовых действий |
| [timer](<Программные модули/Виртуальные модули/timer_sw.md>) | событие по истечении заданного времени |
| [watchdog](<Программные модули/Виртуальные модули/watchdog_sw.md>) | перезагрузка устройства, если его перестали «пинать» |
| [counter](<Программные модули/Виртуальные модули/counter_sw.md>) | счётчик с границами и порогом |
| [flywheel](<Программные модули/Виртуальные модули/flywheel_sw.md>) | «маховик»: счётчик, который сам затухает |
| [random](<Программные модули/Виртуальные модули/random_sw.md>) | случайное число в диапазоне |
| [scaler](<Программные модули/Виртуальные модули/scaler_sw.md>) | линейное приведение значения из одного диапазона в другой |
| [conductor](<Программные модули/Виртуальные модули/conductor_sw.md>) | «вверх / вниз / стоп» по текущей и целевой позиции |
| [tankControl](<Программные модули/Виртуальные модули/tankControl_sw.md>) | танковый микшер: газ + руль → два канала |
| [collector](<Программные модули/Виртуальные модули/collector_sw.md>) | накопитель символов в строку (набор кода, номера) |
| [whitelist](<Программные модули/Виртуальные модули/whitelist_sw.md>) | проверка строки по списку разрешений из файла |
| [masquerade](<Программные модули/Виртуальные модули/masquerade_sw.md>) | ретрансляция значения в другой топик |
| [listOfActions](<Программные модули/Виртуальные модули/listOfActions_sw.md>) | проигрывание сценария — файла со списком действий и пауз `delay_ms` |
| [USB_HID](<Программные модули/Виртуальные модули/USB_HID_sw.md>) | имитация USB-клавиатуры |

Большинство модулей поддерживают `enable` (команда и рапорт) и флаг
**disableOnStart**; исключения — startup, watchdog, masquerade и USB_HID.

## Пример
```ini
[SLOT_6]
mode = startup
;при загрузке - таймер на 30 секунд
crosslink = startup_6/event/started:1->timer_7/action/start:30000

[SLOT_7]
mode = timer
;по таймеру - случайный трек
crosslink = timer_7/event/timerEnd:@->player_0/action/play:random
```

Подробнее — [[Платформа moduleBox/CrossLink|внутренние связи (crossLink)]].
