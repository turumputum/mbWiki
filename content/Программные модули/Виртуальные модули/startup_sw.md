Программный модуль для инициализации при загрузке.

## Принцип работы
Модуль рапортует при старте, соответственно внутренние связи будут выполнены единоразово при включении, можно настроить задержку.

## Топик
Стандартный топик событий и действий:
- *"deviceName/startup"*
	- пример: "moduleBox/startup"

## Опции
Доступные опции:
- **delay** - *число(int)*, время задержки. Единица измерения $мСек$. По умолчанию 50 $мСек$.

Пример
 ```ini
 ;настройка задержки в пол секунды
options=delay:500
```

## Cобытия
- Отчет по завершению загрузки.

Пример использование [[cross_link]]:
```ini
;при включениии указатель будет установлен на трек "1" и включена подсветка в слоте 4-ре
cross_link = startup->player_0/shift:1, startup->led_4:1
```
