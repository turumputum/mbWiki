```ini
[SLOT_n]
mode = startup
```
Виртуальный модуль, отправляющий сообщение при запуске устройства.

## Совместимость
Виртуальный модуль, аппаратной части не требует. Доступные слоты: 0-9.

## Принцип работы
Рапортует один раз при старте — связанные с этим событием действия выполняются
единожды при включении устройства. Опция **delay** задерживает рапорт, чтобы
дождаться инициализации остальных модулей и сетевых служб.

Применяется для установки начального состояния: включить подсветку, выставить
громкость, запустить фоновый трек.

## Топики
База топика события:
- `<deviceName>/startup_<slot>` — например `moduleBox/startup_0`

База топика действия:
- `<deviceName>/startup_<slot>` — например `moduleBox/startup_0`

Полный топик — база плюс направление и имя: `moduleBox/startup_6/event/started`.

## Опции
Доступные опции:
- **delay** — *число(int)*, параметр задержки перед отправкой сообщения о запуске (мс) Числовое значение. По умолчанию 0.

## События
| Топик | Payload | Описание |
|---|---|---|
| `startup_<slot>/event/started` | `0` / `1` | Рапортует при старте Используется для инициализации начального состояния |

Пример: топик `moduleBox/startup_6/event/started`, payload `1`.

## Примеры
```ini
[SLOT_6]
mode = startup
options = delay:2000
;через две секунды после включения запустить фоновый трек и зажечь подсветку
crosslink = startup_6/event/started:1->player_0/action/play:0, startup_6/event/started:1->led_1/action/enable:1
```

Подробнее — [[Платформа moduleBox/CrossLink|внутренние связи (crossLink)]].
