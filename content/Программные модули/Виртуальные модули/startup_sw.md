```
[SLOT_n]
mode = startup
```
Программный модуль для инициализации при загрузке. Виртуальный слот, не взаимодействует с аппаратной частью.
==Виртуальный модуль, использует слоты 6-9.==

## Принцип работы
Модуль рапортует при старте, соответственно внутренние связи будут выполнены единоразово при включении. Можно настроить задержку перед отправкой рапорта.

## Топик
Стандартный топик событий и действий:
- *"deviceName/startup_{slot_num}"* - {slot_num} номер слота
	- пример: "moduleBox/startup_6"

## Опции
Доступные опции:
- **delay** - *число(int)*, задержка перед отправкой рапорта о запуске в $мСек$. От 0 до 4096. По умолчанию 0.
- **topic** - *строка*, нестандартный топик событий и действий.

## События
- **/started** — рапортует значение 1 при завершении загрузки (с учётом задержки). Пример:
	"*moduleBox/startup_6/started*"

## Пример
```ini
[SLOT_6]
mode = startup
;настройка задержки в пол секунды
options = delay:500
;при включении указатель будет установлен на трек "1" и включена подсветка в слоте 4
crosslink = startup_6/started->player_0/shift:1, startup_6/started->led_4:1
```
