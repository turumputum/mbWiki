*артикул 200-001*

![[Устройства/_assets/audioStick.jpg]]
## Описание
Устройство для музейных и выставочных экспозиций: наушник лежит на магнитной
базе; когда посетитель снимает его, начинает играть аудиотрек, когда кладёт
обратно — воспроизведение останавливается. Контент — файл на карте памяти,
питание — от USB-адаптера, сеть не нужна.

## Состав устройства
| Слот | Аппаратный модуль | Программный модуль |
|---|---|---|
| 0 | [soundMono](<Аппаратные модули/soundMono_hw.md>) — моно-усилитель, динамик 100-001 в наушнике | [mp3Player](<Программные модули/Звуковые модули/mp3Player_sw.md>) |
| 1 | [SD_card](<Аппаратные модули/SD_card_hw.md>) — карта памяти с треком | — |
| 2 | [button_led](<Аппаратные модули/button_led_hw.md>) — вход `bt`: геркон магнитной базы 100-004 | [button_led](<Программные модули/Кнопки с подсветкой/button_led_sw.md>) |

Питание — USB-адаптер 5 В (MW SGA12E05, артикул 000-004) в разъём USB
контроллера.

## Схема подключения
![[Устройства/_assets/audioStick.svg]]

Динамик наушника — на `spk+`/`spk-` модуля soundMono. Геркон базы — сухой
контакт между `bt` и `gnd` модуля button_led; подсветка не используется.

## Типовой конфиг
```ini
[SYSTEM]
deviceName = audiostick

[SLOT_0]
mode = mp3Player
options = volume:75
;по окончании трека проиграть его снова
crosslink = player_0/event/endOfTrack:#->player_0/action/play:#

[SLOT_1]
mode = SD_card

[SLOT_2]
mode = button_led
;геркон замкнут, пока наушник на базе: инвертируем, чтобы снятие давало 1
options = buttonInverse
;снятие наушника - трек 0, установка обратно - стоп
crosslink = button_2/event/press:1->player_0/action/play:0, button_2/event/press:0->player_0/action/stop:1
```

- Сетевые интерфейсы не используются, поэтому группы `[LAN]`, `[UDP]`,
  `[OSC]`, `[MQTT]` в конфиге отсутствуют — подробнее в
  [[Платформа moduleBox/Software#Структура конфигурационного файла|структуре конфигурационного файла]].
- Громкость — опция **volume** в `[SLOT_0]`.
- Геркон базы замкнут, пока наушник лежит; **buttonInverse** в `[SLOT_2]`
  переворачивает сигнал, и снятие наушника даёт `press` = `1`.
- crossLink в `[SLOT_0]` зацикливает трек: по `endOfTrack` он запускается
  снова (`#` — текущий трек).
- crossLink в `[SLOT_2]`: `press` = `1` запускает трек 0, `press` = `0`
  останавливает воспроизведение.

Подробнее — [[Платформа moduleBox/CrossLink|внутренние связи (crossLink)]].
